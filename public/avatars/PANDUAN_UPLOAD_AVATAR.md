# 📂 Folder Avatar Server Resmi (`/public/avatars/`)

Silakan **upload (unggah)** file gambar avatar pilihan Anda (format `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, atau `.svg`) langsung ke dalam folder **`/public/avatars/`** ini!

### ✨ Cara Kerja Otomatis (Semua Pemain Langsung Memakai Avatar Anda):

1. **Opsi 1 — Upload 1 Gambar Avatar Saja (Untuk Semua Pemain):**
   - Jika Anda mengupload **1 file gambar** dengan nama bebas (contoh: `avatar-warga.png` atau `pion.png`) ke dalam folder `/public/avatars/`, maka **seluruh pemain** (baik Manusia maupun Bot di semua HP/Laptop) otomatis langsung menggunakan gambar avatar tersebut!

2. **Opsi 2 — Upload Gambar Berbeda untuk Masing-Masing Karakter (Hingga 8 Karakter):**
   - Anda dapat memberi nama file sesuai ID karakter atau nomor urut `1` s/d `8`:
     - `ojol.png` (atau `1.png` / `avatar1.png`) ➔ **Driver Ojol**
     - `emak.png` (atau `2.png` / `avatar2.png`) ➔ **Emak-Emak Matic**
     - `pns.png` (atau `3.png` / `avatar3.png`) ➔ **PNS Konoha**
     - `mahasiswa.png` (atau `4.png` / `avatar4.png`) ➔ **Mahasiswa Abadi**
     - `bakso.png` (atau `5.png` / `avatar5.png`) ➔ **Kang Bakso**
     - `sultan.png` (atau `6.png` / `avatar6.png`) ➔ **Sultan OKB**
     - `kurir.png` (atau `7.png` / `avatar7.png`) ➔ **Kurir Paket**
     - `pengamen.png` (atau `8.png` / `avatar8.png`) ➔ **Pengamen Senja**
   - Atau cukup upload beberapa gambar dengan nama apa saja, sistem akan membagikannya secara otomatis ke seluruh karakter warga!
